# telebot-1

A Telegram bot project deployed on Railway.

## Features
- User approval system
- Command handlers (`/start`, `/help`)
- Message handling for approved users

## Setup
1. Get your bot token from [@BotFather](https://t.me/BotFather)
2. Add the token to `.env` as `BOT_TOKEN=your_token_here`
3. Add user IDs to `approved_users.json`

## Deploy
Push to GitHub and connect to Railway for automatic deployment.
